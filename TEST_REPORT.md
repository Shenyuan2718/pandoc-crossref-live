## Compatibility notes

- Pandoc Reference List processes bibliography citations only after a valid local bibliography and CSL style are configured.
- The plugins operate on disjoint reference types: this plugin handles `eq`, `fig`, and `tbl`; Pandoc Reference List handles non-crossref bibliography keys.
- Reading-mode compatibility recovery handles reference nodes generated by Pandoc Reference List.

## Limitation

Obsidian's reading-mode Markdown parser does not accept a multiline equation closed by `$$ {#eq:id}`. That syntax works in live preview but causes the remaining Markdown to be consumed as math in reading mode. For reading mode, place the equation tag on the following line or use a standard single-line display equation.
